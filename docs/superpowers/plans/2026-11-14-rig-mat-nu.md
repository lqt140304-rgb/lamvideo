# Mặt diễn xuất, IK tay, ngón và da liền màu cho base nữ — Kế hoạch thực hiện

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mở rộng `nhan-vat-nu-rig.blend` để có mắt, mày, miệng diễn được và nói được (khẩu hình tiếng Việt), IK/FK cho tay và chân, 15 đốt ngón, và da liền một màu.

**Architecture:** `rig_nu.py` vẫn là điểm vào duy nhất và vẫn ra một file `.blend`. Phần texture da nằm ở `da_lien_mau.py`: chạy bằng Python thường (numpy + Pillow), đọc texture gốc, ghi texture mới vào thư mục rig. Phần mặt nằm ở `mat_nu.py`: module bpy, được `rig_nu.py` import và gọi sau khi dựng armature. `kiem_rig_nu.py` mở file đã lưu và kiểm từng yêu cầu; script thoát mã khác 0 nếu có lỗi.

**Tech Stack:** Blender 5.2.3 (`D:/blender/blender.exe`), bpy/bmesh/numpy trong Blender; Python 3 hệ thống (`py`) với numpy và Pillow cho texture; bảng ảnh ghép bằng `what-if-studio/tools/soi/bang.cjs`.

**Spec:** [docs/superpowers/specs/2026-11-14-rig-mat-nu-design.md](../specs/2026-11-14-rig-mat-nu-design.md)
