# Phông chữ cho chữ trên bảng / màn chiếu (giảng đường Hồi 3)
- `PatrickHand-Regular.ttf`: Patrick Hand (Patrick Wagesreiter), giấy phép SIL Open Font License 1.1, lấy từ gói npm `@expo-google-fonts/patrick-hand`. Nét viết tay, có dấu tiếng Việt, dùng cho chữ phấn.
- `DejaVuSans.ttf`, `DejaVuSans-Bold.ttf`: DejaVu Sans, cùng giấy phép; đủ dấu tiếng Việt, dùng cho giao diện điện thoại/laptop (UI).
- `DejaVuSansMono.ttf`: DejaVu Sans Mono, giấy phép Bitstream Vera / DejaVu (tự do dùng và phân phối lại). Chữ đơn cách, dùng cho code trên màn chiếu.
- `LiberationSans-Bold.ttf`, `LiberationSans-Regular.ttf`: Liberation Sans, giấy phép SIL Open Font License 1.1. Dùng cho chữ in trên đạo cụ 3D trong Blender, vì DejaVu Sans bị lỗi dấu móc khi ư và ơ đứng liền nhau trong cùng một từ (vd "xương"), còn Liberation Sans hiển thị đúng.
